## 1. Общая информация о проекте

Разработка сайта в формате системы нетематических блогов.

**Технологии разработки:**
- **Backend:** PHP.
- **Frontend:** HTML, CSS, JavaScript (jQuery + Ajax).
- **База данных:** MySQL.
- **Формат обмена данными:** JSON.
- **Система контроля версий:** GIT.
- **CSS-фреймворк:** Bootstrap 3 (первая версия сайта).

## 2. Роли пользователей и их возможности

Каждая следующая роль наследует все права предыдущей роли и дополнительно получает собственные возможности.

### 2.1. Гость

- Просмотр списка публичных постов.
- Возможность поделиться постом в социальных сетях.
- Поиск по постам и пользователям.
- Просмотр отдельных постов.
- Просмотр профилей пользователей и их публичных постов.
- Просмотр дополнительных страниц:
  - Все посты.
  - Случайный пост.
  - Вход.
  - Регистрация.
- Возможность зарегистрироваться и авторизоваться.
- Использование сортировки и фильтров по постам на главной странице.
- Возможность отсканировать QR-код у поста.

### 2.2. Пользователь

Дополнительные возможности:

- Создание собственных постов (отправляются модератору или администратору на проверку).
- Оставление комментариев к постам.
- Редактирование собственных комментариев.
- Оценка комментариев.
- Ответы на комментарии.
- Оценка постов.
- Просмотр списка всех своих постов.
- Изменение аватара.
- Отправка жалоб на пользователей.
- Удаление собственных комментариев.
- Изменение пароля.
- Редактирование информации профиля:
  - Электронная почта.
  - Информация о себе.

### 2.3. Модератор

Дополнительные возможности:

- Редактирование отправленных пользователями постов.
- Публикация отправленных постов.
- Отклонение отправленных постов.
- Рассмотрение жалоб на пользователей.
- Блокировка пользователей, на которых поступили жалобы.
- Просмотр таблицы с жалобами на пользователей.
- Удаление любых комментариев к постам.
- Добавление собственных постов без необходимости прохождения дополнительной модерации.

### 2.4. Администратор

Дополнительные возможности:

- Удаление любых постов.
- Редактирование любых постов.
- Блокировка пользователей.
- Просмотр всех постов.
- Отклонение любых постов.
- Публикация любых постов.
- Управление тегами:
  - Редактирование тегов.
  - Удаление тегов.
  - Изменение статуса тегов.
- Управление категориями:
  - Добавление категорий.
  - Редактирование категорий.
  - Удаление категорий.
- Изменение ролей пользователей.

## 3. Структура проекта

Краткое описание структуры директорий и основных файлов проекта:

```text
project/
│
├── api/                  # PHP-файлы для обработки Ajax-запросов
│
├── components/           # Повторно используемые HTML-шаблоны
│
├── docs/                 # Документация и другие материалы проекта
│
├── pages/                # Файлы отдельных страниц сайта
│
├── public/               # Публичные ресурсы сайта
│   ├── css/              # Стили
│   ├── js/               # JavaScript-скрипты
│   └── img/              # Изображения и иконки
│
├── sql/                  # Схема базы данных и дампы MySQL
│
├── src/                  # Общие PHP-файлы проекта
│   └── usecases/         # PHP-файлы для выполнения логики
│                         # при открытии определённых страниц
│
├── data/                 # Хранение пользовательских файлов
│                         # (аватары, изображения постов и т. д.)
│
├── libs/                 # Сторонние библиотеки
│
├── index.php             # Главный файл приложения
│
└── .htaccess             # Настройки веб-сервера Apache
```

### 3.1. Описание основных элементов

| Элемент | Назначение |
|---|---|
| `api/` | PHP-файлы, к которым обращается frontend через Ajax |
| `components/` | Повторно используемые HTML-шаблоны |
| `docs/` | Документация и материалы, связанные с разработкой |
| `pages/` | Файлы страниц сайта |
| `public/` | Изображения, JavaScript-скрипты, CSS-стили и другие публичные ресурсы |
| `sql/` | Схема базы данных и дампы MySQL |
| `src/` | PHP-файлы с общей логикой проекта |
| `src/usecases/` | PHP-файлы для выполнения определённых действий при открытии страниц |
| `data/` | Пользовательские изображения и файлы постов |
| `libs/` | Сторонние библиотеки |
| `index.php` | Главная точка входа в приложение и обработчик маршрутизации |
| `.htaccess` | Настройки Apache, включая правила перенаправления запросов |

### 3.2. Принцип работы `index.php`

`index.php` является главной точкой входа в приложение.

Основные задачи:
1. Получение URL-адреса текущего запроса.
2. Определение необходимой страницы (маршрутизация).
3. Подключение соответствующих PHP-файлов и компонентов.
4. Передача управления необходимой логике приложения.
5. Отображение страницы пользователю.

Все переходы по URL обрабатываются через `index.php`, что позволяет централизованно управлять маршрутизацией сайта.
